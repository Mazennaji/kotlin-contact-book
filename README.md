## ✨ Overview

This project is a hands-on journey through core Kotlin concepts. Every feature is committed as its own step, making the repository a readable, chronological guide to how the app was built.

## 🚀 Features

- ➕ **Add contacts** with built-in duplicate detection
- 🗑️ **Remove contacts** by phone number
- 🔍 **Search contacts** by name (case-insensitive)
- 📋 **List all contacts** with clean numbered output
- 🛡️ **Null-safe** email handling

## ▶️ Getting Started

### Prerequisites
- JDK 17 or higher
- IntelliJ IDEA (Community or Ultimate)

### Run it

```bash
git clone https://github.com/<your-username>/kotlin-contact-book.git
cd kotlin-contact-book
```

Open the project in IntelliJ IDEA and run the `main` function in `Main.kt`.
